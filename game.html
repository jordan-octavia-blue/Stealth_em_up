I created this game many years ago while I was first learning how to program. It's not polished, and coded rather poorly, but it was a lot of fun to make and I learned a lot. Enjoy!

Controls:
Movement W,A,S,D
Sprint Shift
Draw Gun Right Mouse Button (toggle)
Shoot (when gun is drawn) Left Mouse Button
Reload Gun R
Put on Mask V
Interact Space
Navigation debug overlay N (cycles paths / regions / danger / flow field)
